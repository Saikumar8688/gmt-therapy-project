# Grow My Therapy — Counseling Website Assignment

A responsive Next.js + Tailwind CSS project with two routes:

- `/` — homepage recreation inspired by Conejo Valley Family Counseling's public homepage structure.
- `/maya` — a fresh visual concept for the fictional Dr. Maya Reynolds profile, including services, About, Our Office, FAQs, and contact CTA.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. The `dev` script is included in `package.json` (this addresses `npm error Missing script: "dev"`).

## Build for production

```bash
npm run build
npm start
```

## Before submitting

1. Read the supplied Dr. Maya Reynolds profile and replace any placeholder or generic copy with profile-accurate facts.
2. Replace illustrative office photos with the actual photos supplied in the profile.
3. Update the demo email link and contact details with verified details only.
4. Compare the `/` page against the original site at desktop, tablet and mobile widths; exact pixel matching requires manual visual comparison.
5. Deploy to Vercel, push the repository to GitHub, and record the five-minute Loom walkthrough.

Images use remote Unsplash URLs and Google Fonts, so an internet connection is needed for those assets. This is a student recreation/concept, not an official site and not affiliated with Conejo Valley Family Counseling.
